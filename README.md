> ## Description

This application is a comprehensive employee absence management system designed to streamline the process of tracking and managing absences in an organization. It provides intuitive interfaces for managing employees, logging absences, categorizing absence types, and viewing absences details on a centralized dashboard. With features like interactive tables and strong data typing, the application ensures scalability, reliability, and a seamless user experience. Perfect for organizations of any size, this tool helps maintain accurate absence records while promoting efficient team management.

## Tech Stack

- **Electron**: For building the desktop application, providing a seamless native experience across operating systems.
- **React**: For creating dynamic and interactive user interfaces.
- **Tailwind CSS**: For fast and customizable styling of components.
- **MySQL**: As the relational database for storing and managing application data.


## Features

- **User Authentication**:
  - Login functionality for secure access to the application.

- **Absence Management**:
  - Add, edit, delete, and view employee absences.
  - Categorize absences with predefined types.
  - Filter and sort absences in an interactive table.

- **Employee Management**:
  - Manage employees with functionalities to add, edit, and delete employee details.
  - Display employee list in a structured table.

- **Absence Type Management**:
  - Define and manage different types of absences.
  - View and edit absence types in a dedicated table.

- **Dashboard Overview**:
  - Centralized page displaying all absences with functionality to filter them and export them as xlsx.

- **Navigation**:
  - Intuitive navigation bar for seamless access to key pages like Dashboard, Absence Management, Employee Management, and more.

- **Data Models**:
  - Strongly-typed data structures using TypeScript for better maintainability and error prevention.

- **Interactive Tables**:
  - Tables with features like sorting, filtering, and action buttons for efficient data management.

- **Scalable Design**:
  - Modular architecture that ensures easy addition of new features or components in the future.
